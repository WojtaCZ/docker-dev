# CH32V003fun C++ Project Template

Set up a C++ project using ch32v003fun as the bare-metal scaffolding for WCH CH32V003 and compatible devices.

## Project structure

```
firmware/
├── Makefile
├── src/
│   └── main.cpp
└── .mcu-profile.json    ← generated by /scaffold-mcu-project wch
```

## Minimal Makefile

ch32v003fun ships its own `Makefile` with `$(CH32V_FUN)/minichlink/` as the flasher. Adapt for C++:

```makefile
TARGET     ?= firmware
SRC_DIR     = src

# ch32v003fun path (set in the container)
CH32V_FUN  ?= /opt/ch32v003fun

# Toolchain
PREFIX      = riscv-none-elf-
CC          = $(PREFIX)gcc
CXX         = $(PREFIX)g++
OBJCOPY     = $(PREFIX)objcopy
SIZE        = $(PREFIX)size

# Flags common to C and C++
COMMON_FLAGS = \
    -march=rv32ec \
    -mabi=ilp32e \
    -Os \
    -ffunction-sections \
    -fdata-sections \
    -I$(CH32V_FUN) \
    -DSYS_CORE_CLK=48000000

CFLAGS      = $(COMMON_FLAGS) -std=c11
CXXFLAGS    = $(COMMON_FLAGS) \
    -std=c++20 \
    -fno-exceptions \
    -fno-rtti \
    -fno-threadsafe-statics

LDFLAGS     = \
    -T $(CH32V_FUN)/ch32v003fun/ch32v003fun.ld \
    -Wl,--gc-sections \
    -Wl,-Map=$(TARGET).map \
    -nostdlib \
    $(CH32V_FUN)/ch32v003fun/ch32v003fun.c   # startup + syscalls

SRCS_CPP    = $(wildcard $(SRC_DIR)/*.cpp)
SRCS_C      = $(wildcard $(SRC_DIR)/*.c)
OBJS        = $(SRCS_CPP:.cpp=.o) $(SRCS_C:.c=.o)

all: $(TARGET).elf $(TARGET).bin
    $(SIZE) $(TARGET).elf

$(TARGET).elf: $(OBJS)
    $(CXX) $(CXXFLAGS) $(LDFLAGS) -o $@ $^

%.o: %.cpp
    $(CXX) $(CXXFLAGS) -c -o $@ $<

%.o: %.c
    $(CC) $(CFLAGS) -c -o $@ $<

$(TARGET).bin: $(TARGET).elf
    $(OBJCOPY) -O binary $< $@

flash: $(TARGET).bin
    wlink flash $(TARGET).bin

clean:
    rm -f $(OBJS) $(TARGET).elf $(TARGET).bin $(TARGET).map

.PHONY: all flash clean
```

## Minimal `src/main.cpp`

```cpp
// CH32V003 bare-metal C++ entry point
// ch32v003fun handles startup, .data copy, .bss zero, and calls main()
extern "C" {
    #include "ch32v003fun.h"
}

// GPIO toggle example — PA2 (any available pin)
static void clock_init() {
    RCC->APB2PCENR |= RCC_APB2Periph_GPIOA;
}

static void gpio_init() {
    // PA2: push-pull output, 50 MHz
    GPIOA->CFGLR = (GPIOA->CFGLR & ~(0xF << 8)) | (0x3 << 8);
}

int main() {
    SystemInit();
    clock_init();
    gpio_init();

    for (;;) {
        GPIOA->BSHR = (1 << 2);    // set PA2
        Delay_Ms(500);
        GPIOA->BCR  = (1 << 2);    // reset PA2
        Delay_Ms(500);
    }
}
```

## Notes on C++ with ch32v003fun

- `ch32v003fun.h` is a C header — wrap includes in `extern "C" { }` or in a `.c` file.
- `ch32v003fun.c` provides `Delay_Ms`, `SystemInit`, startup code. It is compiled as C, which is fine — C++ can call C functions without issues.
- The linker script (`ch32v003fun.ld`) exports `__init_array_start` / `__init_array_end`; confirm with `nm`:
  ```bash
  riscv-none-elf-nm firmware.elf | grep init_array
  ```
  If missing, global C++ constructors will not run — add `__libc_init_array()` call after `SystemInit()` in the startup C file, or switch to a custom startup `.cpp`.
